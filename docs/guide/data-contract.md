# CSV input format

The command-line utility and public Demo use the same six-column CSV format. Each upload contains 336 consecutive hourly rows for one cell.

## Required header

```text
时间,小区名称,小区上行平均激活用户数,小区下行平均激活用户数,下行平均使用的PRB个数,上行平均使用的PRB个数
```

| Field | Rule |
| --- | --- |
| `时间` | `YYYY/MM/DD HH:MM`, strictly hourly and increasing |
| `小区名称` | One non-empty value shared by all 336 rows |
| Four indicators | Finite, non-negative number, `NIL`, or blank |
| Row count | Exactly 336 data rows for the public Demo |
| Encoding | UTF-8 or UTF-8 with BOM |
| Upload size | At most 5 MB on the public Space |

The forecast begins one hour after the final row and covers the next 24 hours. `NIL` or a blank field indicates a missing value. A Boolean mask preserves this information inside the model, ensuring that a placeholder number is never treated as a real observation.

## Minimal preview

```csv
时间,小区名称,小区上行平均激活用户数,小区下行平均激活用户数,下行平均使用的PRB个数,上行平均使用的PRB个数
2026/07/01 00:00,synthetic-cell,18.0,26.0,32.0,14.0
2026/07/01 01:00,synthetic-cell,18.1,26.2,NIL,14.1
```

The complete bundled example is available at [`demo/examples/synthetic_traffic.csv`](https://github.com/rudykon/WLCR-SEA_Predictor/blob/main/demo/examples/synthetic_traffic.csv). It is generated by code, always contains the same values, and includes no real operator or participant data.

## Programmatic validation

```python
from Model.traffic_window_forecasting import read_traffic, split_physical_windows

rows = read_traffic("request.csv")
windows = split_physical_windows(rows)
assert len(windows) == 1
assert not windows[0].gaps
```

!!! warning "Do not upload confidential data"
    Do not upload confidential operational traffic to the public Space. The app is not designed to save requests, but Hugging Face is shared public infrastructure. For sensitive data, run `demo/app.py` in your own controlled environment.
