# 结构化季节专家路由

WLCR-SEA 针对每个预测步和每个指标构建八个有限候选。路由器读取它们的数值与可用性，
而不是依赖隐藏且不受约束的特征库。

## 八个专家

| 专家 | 请求局部证据 | 可用规则 |
| --- | --- | --- |
| 前一天 | 目标同一小时的一日前数值 | 该观测存在 |
| 前一周 | 七日前同一小时 | 该观测存在 |
| 两周滞后 | 十四日前同一小时 | 该观测存在 |
| 7 日同小时中位数 | 七个季节位置的稳健中位数 | 至少一个位置存在 |
| 14 日同小时中位数 | 十四个位置的稳健中位数 | 至少一个位置存在 |
| 有界周趋势 | 前周值加裁剪后的周变化 | 周与双周值均存在 |
| 窗口局部中位数 | 当前 336 小时请求的中位数 | 指标至少有一个值 |
| 冻结训练先验 | 预测步—指标训练中位数 | 完成训练后始终可用 |

缺失位置在内部可以有任意数值填充，但掩码具有最终权威性。人工移除后，所有汇总都会重新计算，
因此被删除值不能通过填充值泄漏。

## 可用集路由

所选模型在**压缩后的可用专家集合**上执行按预测步设置的 Entmax，再把概率散射回八个槽位。
因此不可用专家的质量在结构上严格等于零，而不是通过一个很小的有限哨兵值近似为零。

可靠度特征表示中位数或汇总专家获得了多少支持，但它不能覆盖可用性判断。

## 有界残差

路由凸组合形成对数空间基线。学习残差先经过 `tanh`，再乘以固定边界，因此预测始终位于：

\[
\left[\min_{j \in A} e_j - b,\; \max_{j \in A} e_j + b\right]
\]

其中 \(A\) 是可用专家集合，\(b\) 是残差边界。

## 审计字段

可重放记录可以保留请求哈希、模型版本、专家值、可用性、可靠度、路由权重、残差、基线、
预测和范围检查。仓库中的审计程序还会验证字段白名单，防止身份条件输入悄然进入评分器。
