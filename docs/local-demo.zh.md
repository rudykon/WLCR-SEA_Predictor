# 本地 Demo

直接使用你电脑的 CPU，在浏览器中完成预测，无需安装 Python、登录或调用推理服务器。
模型资源从本站加载，选择的 CSV 文件留在你的设备上。

<div class="local-demo" data-local-demo data-lang="zh">
  <noscript>请启用 JavaScript 后运行本地预测。</noscript>
</div>

六列 CSV 格式见[数据契约](guide/data-contract.md)。本页与项目 Demo 使用相同的
[五个公开检查点](https://huggingface.co/config-h/WLCR-SEA-Predictor/tree/eb4447f4ebab8f9caa003d92c838ed8e750963bd)。
缺失模拟沿用种子 2026 的单请求协议，不代表对多请求评测的复现。

也可以打开由服务器计算的 [Hugging Face Demo](https://huggingface.co/spaces/config-h/WLCR-SEA_Predictor)。
