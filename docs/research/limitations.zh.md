# 适用边界与局限

现有证据支持研究和受控测试，但不足以证明模型无需调整就能适用于所有地区、季节或真实网络。主要局限如下。

## 数据与泛化

- 研究只覆盖一个匿名区域约一个月。
- 所有预测都从午夜开始，因此研究无法区分“距离预测起点多远”和“每天几点钟”各自的影响。
- 八月测试集曾影响部分设计选择，所以最终结论仍应视为探索性结果。
- 即使训练集和测试集使用不同小区，数据仍来自同一地区，因此不能证明模型在跨地区、跨运营商或跨季节条件下的表现。
- 更换数据采集系统、指标定义或流量模式后，需要重新评估。

## 精度解释

- DLinear 在报告对比中拥有最低的完整数据 WAPE。
- 在完整数据下，WLCR-SEA 与先前仅使用流量数据的方法之间，差异的置信区间包含 0，因此尚不能确认存在明确差异。
- 在部分中等缺失率下，相对某些基线的差异同样不明确。
- 数据缺失场景中最显著的结果，只适用于研究采用的固定移除模式和训练过程。
- 本研究中的路由熵不能作为可靠的不确定性估计。

## 服务与隐私

在一次预测中，模型不能利用小区 ID 获取额外流量数据，但这一限制本身并不能提供：

- 访问控制或授权；
- 静态或传输加密；
- 匿名化或差分隐私；
- 对日志、缓存、入口服务或下游系统的安全保证。

小区 ID 仍可保留在模型之外，用于权限控制和记录。生产系统仍需制定明确的数据留存、日志管理、加密密钥和事件响应规则。

## 公开 Demo 边界

仓库没有提供训练后的 A6 检查点和训练集回退值。因此，公开 Space 运行较简单的 `A0_fixed` 基线，并根据当前输入计算最终回退值。它可以展示计算步骤，但运行的并不是论文所用的训练模型。

!!! danger "不要把 Demo 输出与论文表格直接比较"
    如需复现论文结果，请使用文档规定的数据集、数据划分、训练流程、检查点和评估脚本。
