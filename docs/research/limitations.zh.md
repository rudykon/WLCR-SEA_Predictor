# 适用边界与局限

现有证据支持研究和受控测试，但不足以证明模型无需修改就能适用于所有地区、季节或真实网络。
主要局限如下。

## 数据与泛化

- 研究只覆盖一个匿名区域约一个月。
- 所有预测都从午夜开始，因此研究无法区分“距离预测起点多远”和“每天几点钟”各自的影响。
- 八月测试集曾影响部分设计选择，所以最终结论仍应视为探索性结果。
- 训练和测试使用不同小区的实验仍来自同一地区数据，不能证明跨地区、跨运营商或跨季节表现。
- 更换数据采集系统、指标定义或流量模式后，需要重新评估。

## 精度解释

- DLinear 在报告对比中拥有最低的完整数据 WAPE。
- 完整数据下，WLCR-SEA 与先前仅流量方法的置信区间包含 0，差异并不明确。
- 在部分中等缺失率下，相对某些基线的差异同样不明确。
- 最强的缺失数据结果只适用于论文采用的固定移除模式和训练过程。
- 本研究中的路由熵不能作为可靠的不确定性估计。

## 服务与隐私

模型在一次预测中不能根据小区 ID 获取额外流量，但这一限制本身并不提供：

- 访问控制或授权；
- 静态或传输加密；
- 匿名化或差分隐私；
- 日志、缓存、入口服务和下游消费者安全保证。

小区 ID 仍可存在于模型之外，用于权限控制和记录。生产系统仍需要明确的数据留存、日志、
加密密钥和事件响应规则。

## 公开 Demo 边界

仓库没有提供训练后的 A6 检查点和训练集回退值。公开 Space 因此运行较简单的 `A0_fixed`
基线，并使用当前输入计算最终回退值。它可以展示计算步骤，但不是论文中的训练模型。

!!! danger "不要把 Demo 输出与论文表格直接比较"
    要复现论文，请使用文档规定的数据集、划分、训练流程、检查点和评估脚本。
