# 适用边界与局限

本项目适合研究和受控测试。上线前必须重新验证。

## 数据与泛化

- 一个匿名区域，约一个月。
- 所有预测从午夜开始，预测步长与时刻影响无法分开。
- 八月测试集影响过部分设计选择。
- 小区不重叠测试仍来自同一地区。
- 新地区、季节、指标或采集系统都需重测。

## 精度解释

- DLinear 的完整数据 WAPE 最低。
- WLCR-SEA 与先前方法在完整数据下差异不明确。
- 部分中等缺失率对比也不明确。
- 缺失数据优势仅适用于已测试的模式和训练。
- 路由熵不是可靠的不确定性估计。

## 服务与隐私

禁止按小区 ID 查询数据，**并不等于**提供：

- 访问控制或授权；
- 静态或传输加密；
- 匿名化或差分隐私；
- 对日志、缓存、入口服务或下游系统的安全保证。

生产系统仍需访问控制、数据留存、安全日志、加密和事件响应。
